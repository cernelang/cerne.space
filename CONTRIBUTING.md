# Contributing to cerne.space
If you're planning on contributing to Cerne (specifically, this sub-repository of The Cerne Project), you first must know a few things:
- By contributing to Cerne, you agree to license your **contributions** under the **[CC BY-SA 4.0 License](LICENSE)**
- Any contribution is a valid contribution as long as it serves a purpose described by your contribution's description.

<ins>You retain copyright to your contributions.</ins>

## Important Notice
Please remember that each component of The Cerne Project uses a different license and is located in different places, **<ins>this repository</ins>** is considered to fall under the **"Specification & Documentation"** category so any and all contributions to this repository fall under the license applicable for that, which is the **[CC BY-SA 4.0 License](LICENSE)**. 

If you plan to contribute to: 
- The Documentation itself (**the markdown files**)
- The Standard Library 

or 

- The Compiler

please see yourself following [Cerne's main repository](https://github.com/kashiexe/cerne).
